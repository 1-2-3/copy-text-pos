Editor support at a glance

There is no universal Windows API for a file path plus selection line range. Support is layered and honest.

local-first
Editor Path Line range How
VS Code · Cursor · Windsurf · VSCodium exact exact Bridge extension, window title, workspace index
IntelliJ IDEA · Android Studio · PyCharm · WebStorm · GoLand · CLion · Rider exact scanned Copy Reference probe + selection search
Obsidian good inferred Vault registry + Markdown-aware search
Typora good inferred Recent-file history + Markdown-aware search
Sublime Text · Notepad++ · EmEditor · Notepad depends inferred Full path in title or configured search roots
Terminals · browsers · Office documents — — Not plain files with a selection. Terminal windows are skipped.

Ranges are inclusive. Duplicate snippets without a bridge or title line hint resolve to the first occurrence. Inferred ranges can be wrong if the buffer is unsaved or the selection was rendered Markdown.
